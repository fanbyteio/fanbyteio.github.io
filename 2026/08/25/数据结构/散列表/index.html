散列

基本概念

概念 含义
散列 通过计算直接确定数据存储位置的查找方法
散列表 按照散列值存储数据的数据结构
槽 slot 散列表中保存数据的位置
散列函数 将键转换为槽下标的函数
散列值 散列函数计算得到的槽下标
表长 m 散列表中槽的总数
冲突 不同键得到相同散列位置
负载因子 表中元素数量与槽数量的比值

散列函数可以表示为：==键 → 散列函数 → 槽下标==
散列函数的输出范围为：==0 ～ m - 1==

负载因子

负载因子通常记为：

负载因子情况 影响
较小 空槽多，冲突概率较低
较大 表逐渐变满，冲突概率增加
接近表容量上限 插入和查找效率明显下降

完美散列函数

完美散列函数是指：将给定集合中的每个键映射到不同槽位，不产生散列冲突的散列函数。

获得完美散列函数的一种方法是扩大散列表的容量，大到所有可能出现的数据项都能够占据不同的槽(slot)。但这种方法对于可能数据项范围过大的情况并不实用。所以需要退而求其次，寻找近似完美的散列函数，好的散列函数需要具备：冲突最少(近似完美)、计算难度低(额外开销小)、充分分散数据项(节约空间)。

常见散列函数设计方法

方法 基本思想 特点
求余法 用键除以表长并取余数 简单、常用
折叠法 将键分段后相加，再对表长取余 适合较长的数字键
平方取中法 将键平方，提取中间部分，再取余 能利用键的更多数字特征
字符编码法 将字符串中的字符转换为编码后计算 用于字符串键
加权字符编码法 根据字符位置设置权重后计算 能区分字符相同但顺序不同的字符串

这些方法的目标不是保证完全无冲突，而是让键在散列表中分布得更均匀。

求余法

求余法是最基本的散列函数：

要点 说明
输出范围 0～table_size-1
优点 计算速度快、实现简单
缺点 数据规律可能造成集中冲突
表长选择 通常优先选择质数

取余操作通常也会作为其他散列方法的最后一步，用来保证结果位于合法槽位范围内。

平方取中法

平方取中法的处理过程：

平方运算可以使键的不同部分相互影响，再通过中间数字生成散列值。

优点 缺点
能打乱部分原始规律 计算量高于简单求余
可以改善数据分布 不能保证完全无冲突
利用了键的多个数位 提取规则需要统一

字符串散列

字符串不能直接作为槽下标，需要先转换为数值。

基本过程：

方法 问题或特点
字符编码直接求和 无法有效区分字符顺序
字符编码加权求和 将字符位置加入计算
最后对表长取余 保证结果处于合法槽位范围

字符串散列不仅要使用字符本身的信息，还应考虑字符所在的位置。

冲突

当两个不同的键经过散列函数计算后，得到相同槽下标时，就发生了散列冲突。
冲突无法完全避免，因此散列表必须规定统一的冲突解决方案。

开放寻址法

开放寻址法发生冲突后，会继续在散列表中寻找其他空槽。
所有数据都直接存储在散列表内部。

线性探测

发生冲突后按照固定间隔依次检查后续槽：

重新散列函数通常表示为：

优点 缺点
实现简单 容易产生数据聚集
不需要额外链表 表越满，探测距离越长
数据集中存储 删除操作处理较复杂

线性探测容易使数据集中在一段连续区域中，即聚集现象。
聚集会导致：

  • 新元素需要检查更多槽；
  • 查找需要进行更多比较；
  • 后续冲突进一步增加。

跳跃探测

发生冲突后，不逐个检查槽，而是按照固定步长跳跃。
需要注意的是skip的取值，不能被散列表大小整除，否则会产生周期，造成很多空槽永远无法探测到，通常可以：

  • 将散列表的大小设置为质数(素数)；
  • 使步长与表长互质。

链地址法

链地址法允许同一个槽保存多个数据项。
每个槽指向一个集合或链式结构，冲突的元素存储在同一个槽对应的集合中。

优点 缺点
不需要寻找其他空槽 需要额外存储结构
表较满时仍可以插入 同一槽元素过多时查找变慢
删除操作较直观 冲突严重时可能退化为顺序查找

抽象数据类型 “映射”：ADT Map

映射的定义

映射 Map 是由一组键值对组成的数据结构。

其主要特点是：

特点 含义
按键访问 通过键查找对应的值
键唯一 一个映射中不能存在重复键
值可以重复 不同键可以关联相同的值
无序抽象结构 映射抽象数据类型本身不规定位置顺序
一对一关联 每个键只关联一个当前值

当插入已经存在的键时，不会增加新键，而是更新对应的值。

映射的基本操作

操作 功能
Map() 创建空映射
put(key, value) 添加键值对；键存在时更新值
get(key) 根据键获取值
del map[key] 删除指定键值对
len(map) 或 size() 返回键值对数量
key in map 判断键是否存在

映射抽象数据类型只规定：

  • 数据应具有什么特征；
  • 应支持哪些操作；
  • 每个操作应产生什么结果。

它不规定底层必须使用哪种数据结构。

使用散列表实现映射

列表 保存内容
slots 保存键
data 保存值

插入操作put

插入过程：

  1. 通过散列函数计算键的初始槽；
  2. 如果槽为空，保存键和值；
  3. 如果槽中已经是相同的键，更新对应值；
  4. 如果槽中是其他键，说明发生冲突；
  5. 按重新散列规则寻找可用位置。

查询操作get

查询过程：

  1. 计算键的初始槽；
  2. 比较槽中的键；
  3. 若键相同，返回对应值；
  4. 若键不同，按照相同的探测规则继续查找；
  5. 遇到终止条件后，判定键不存在。

Python特殊方法

为了使自定义映射支持字典形式的访问，可以实现：

特殊方法 对应功能
__getitem__ 获取指定键的值
__setitem__ 插入或修改键值对
__contains__ 判断键是否存在
__len__ 获取键值对数量
__delitem__ 删除键值对

散列表实现映射的复杂度

操作 平均复杂度 最坏复杂度
插入 put O(1) O(n)
查询 get O(1) O(n)
判断键存在 O(1) O(n)
删除 O(1) O(n)

最坏情况通常出现在：

  • 大量键发生冲突；
  • 散列函数分布不均；
  • 负载因子过高；
  • 冲突解决效率较低。
